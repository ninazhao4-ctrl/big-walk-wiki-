Big Walk Game Updates & Patch Notes

A short, source-linked record of recent patches and the practical changes that matter when your group plays together.

Latest update: the newest entry in House House’s official version history is 1.5.1. It adds separate audio volume sliders and includes fixes for saves, connection feedback, passwords, accessibility fonts and a long-distance voice tool.

Last checked: September 1, 2026. This fan-made page summarises public patch notes; the official Big Walk version history is the final authority.

Version 1.5.1: audio, joining and save fixes

The main player-facing addition is separate volume sliders for different audio categories. This is especially useful for groups balancing voice communication against the game’s sound effects. The patch also improves the message shown for slow versus unstable connections and clears the password prompt after a failed joining attempt.

  • Separate audio-category volume controls.
  • A fix for an older save issue where a completed challenge could reset and become impossible to finish.
  • Clearer network warnings for slow or unstable connections.
  • Chinese, Japanese and Korean text rendering fixes.
  • A longer reach for the item used to amplify a player’s voice.

If a friend still cannot connect after this update, restart the game on every platform, confirm the host’s password carefully, then work through the cannot join a friend checklist.

Version 1.5.0: a small collision fix

Version 1.5.0 fixes one area of trees that was missing collision. It is a small patch, but it is worth having every player fully updated before investigating a strange route, fall or stuck position.

Version 1.4.10: connection and voice stability

Version 1.4.10 focused on the situations most likely to interrupt a group session: network stability, disconnects, clearer connection errors and voice reliability. It also added host and join-menu warnings when the game detects a problem that could prevent a connection.

  1. Read any host or join warning before retrying the same connection.
  2. Ask the group to restart after installing a patch.
  3. Use the new audio controls if voice is being covered by other game sounds.
  4. For repeat connection problems, check the hosting guide and the crossplay guide.

Older updates that still affect groups

Version 1.4.9 made session passwords required when starting a game and added settings such as Invert Look X, a frame-rate limit and extra Vsync options. It also added better protection against potential save-data loss. Version 1.4.8 improved quiet player voices, while 1.4.7 improved host stability and the friends’ game browser.

Updates FAQ

Where are the official patch notes?

Use the official version history from House House. Steam’s Big Walk announcements also publish update posts.

Should every friend update before joining?

Yes. Make sure everyone restarts their game client after an update before treating a failed join as a wider multiplayer problem.

Does this page announce future content?

No. It records published patch notes only. We update this page when the official history changes.
