Multiplayer guide

Big Walk Crossplay

Yes—Big Walk supports cross-platform play across its released platforms. Here is what each friend group needs to know.

Quick answer: Crossplay is supported between Steam on Windows/Mac, PlayStation 5, Nintendo Switch 2 and the Mac App Store release.

Crossplay support by platform

Combination Status
Steam ↔ Steam Supported
Steam ↔ PS5 Supported
Steam ↔ Switch 2 Supported
PS5 ↔ Switch 2 Supported
Xbox ↔ other platforms Not applicable; no Xbox release is currently planned

How to play with friends

One player hosts a session and chooses the world configuration. Friends on the same platform service may see the active game automatically. Mixed-platform groups can use the short Join Code generated whenever the host starts a session; the host shares that code privately and the others enter it from the join menu.

Before your group joins

  • Update every copy of the game to the current version.
  • Use a password if you want to control who can enter with a shared Join Code.
  • Confirm crossplay is enabled in each player’s settings.
  • Set device clocks correctly if joining repeatedly fails.
  • Choose a 2-player, 3-player or 4+ world based on the minimum reliable group size.

Crossplay FAQ

Does crossplay change the puzzles?

No. The host’s player-count world setting changes some challenge configurations; the platform mix does not.

Does Big Walk have matchmaking?

No public matchmaking is provided. Organize a group and join a friend or hosted session.
