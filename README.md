# Big Walk Wiki & Guides

A dependency-free, multi-page static site prepared for GitHub Pages and the `bigwalkgames.com` custom domain.

## Included

- Home, puzzles, map, crossplay, player-count, PS5, Xbox and Steam pages
- English, French, Arabic, Spanish and Simplified Chinese interface switching
- Dark/light theme switching; both preferences are remembered locally
- Responsive navigation and layouts for 320–430px phones
- Full navigation/footer logo plus favicon, Apple touch icon and web-app icons
- Local gameplay screenshots, with no third-party or competitor links
- Metadata, manifest, robots file and sitemap for search indexing

## Publish

Upload the project to a GitHub repository, then enable **Settings → Pages → Deploy from a branch** and select the repository root.

All page links are relative, so the site works on both a custom domain and a GitHub project subpath. Canonical and sitemap URLs currently target `https://bigwalkgames.com/`; change those values before publishing under a different domain.

## Media

The included gameplay images are the locally packaged Big Walk screenshots from the prior project. The website logo and icon set are organized as transparent PNG/ICO assets under `assets/brand/`.
